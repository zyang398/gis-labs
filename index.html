The lab layers

The four layers mirror those of the ArcGIS practice lab, and each one is stored in a different coordinate system. ArcGIS Pro reprojects layers on the fly so they line up on the map. A geoprocessing tool measures in the coordinate system it runs in, which is why the Buffer Lab measures its 150 ft in the curves' State Plane feet.

LayerWhat it holdsCoordinate system
Collision480 synthetic crashes in Georgia, invented by a program for these pages and all dated 12 April 2023, each with a route ID and milepoint in GDOT's format. None is a real crash recordWGS 84 (latitude, longitude)
D7_Curves769 synthetic horizontal curves, detected by a program from the bends in the District 7 state-route centerlines; not an official curve inventoryNAD 1983 State Plane Georgia West, US feet
GeorgiaRoadSegments_SRState-route segments with AADT, lanes and speed limit; the labs use the 5,563 in District 7NAD 1983 Georgia Statewide Lambert, US feet
GA_CountiesGeorgia's 159 counties with the FEMA National Risk IndexWGS 1984 Web Mercator, metres
Each page opens in a new tab, and every page has the same six-language menu. Slide numbers refer to the 2026 decks in the lectures folder. District 7 is GDOT's metro Atlanta district: Clayton, Cobb, DeKalb, Douglas, Fulton and Rockdale counties.

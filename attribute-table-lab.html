Attribute Table Lab

An attribute table holds the facts about every feature on the map. Put 480 synthetic crashes on the map, then sort, query, add and calculate fields and summarize them, in the order ArcGIS Pro does it. Each step shows what changes on the map and what changes in the stored data.

Export Features

CSV header → shapefile field name

ArcGIS replaced the characters a shapefile does not allow (spaces, #, :, /, parentheses) with underscores, put an F in front of names that did not start with a letter, and cut every name to 10 characters (slide 14).

In ArcGIS Pro, Display XY Data runs the XY Table To Point tool, which writes a new feature class that already has an ObjectID. In ArcMap (the 2022 slides) it made a temporary XY event layer without one, so slide 6 exports the layer to a shapefile to get a unique ID. On this page that shapefile is Collision.shp.

Pitfalls students hit

      

        
    
          
  • X is longitude and Y is latitude. Swapping them is the most common Display XY mistake.
    • 
          
  • Degree values need a geographic coordinate system. Choosing a projected one, such as State Plane in feet, piles every point on one spot (slide 7).
    • 
          
  • Without an ObjectID, ArcMap could not select or query records reliably. Export first (slide 6).
    • 
          
  • Numbers or dates stored as Text sort letter by letter.
    • 
          
  • '%angle%' and '%Angle%' can give different answers. Mind the case, or use UPPER().
    • 
          
  • Calculate Field with a selection writes only the selected rows. In a shapefile the rest hold 0, which looks like a real value.
    • 
          
  • Integer fields (Short, Long) cannot keep decimals. Store rates in Float or Double.
    • 
          
  • Statistics describe the selected set only. Placeholder values such as 1000 or −1 distort them.

Slide 2 lists the one-table operations in this order. Each card names the slides and the ArcGIS Pro command that does the same thing.

    

    

      

        
Display XY DataSlides 3–7

        
A CSV has coordinates but no geometry. Display XY Data reads the X field as longitude and the Y field as latitude, in the geographic coordinate system you choose. Slide 7: select a GCS and remove any PCS.

        
ArcGIS Pro: right-click the table › Display XY Data (the XY Table To Point tool), then Export Features. ArcMap: Display XY Data, then Export Data.

        

      

      

        
SortingSlide 8

        
Sorting reorders the rows on screen. It has no effect on the original data.

        
ArcGIS Pro: right-click a field header › Sort Ascending or Sort Descending, or double-click the header. The Sort geoprocessing tool writes a new dataset instead.

        

      

      

        
Select By AttributesSlides 9–11

        
A where clause picks the records that meet a condition, such as fatalities ≥ 1 or a manner of collision containing “Angle”. Show the selected records, switch the selection or clear it.

        
ArcGIS Pro: Map tab › Select By Attributes; in the table, Show Selected Records, Switch and Clear.

        

      

      

        
Field types and Add FieldSlides 12–13

        
Choose the type before you add the field. Once a field holds data, ArcGIS will not change its type; you add a new field and calculate it again.

        
ArcGIS Pro: the Add Field tool, or the Fields view of the table (Data Design › Fields).

        

      

      

        
Calculate FieldSlide 14

        
Writes the result of an expression into a field, for every record or only the selected ones. Shapefile field names are cut to 10 characters, so “# of Fatalities (Collision Table)” becomes F__of_Fata.

        
ArcGIS Pro: Calculate Field, Python 3: !F__of_Fata! * 5 + !F__Serious! * 3 + !F__Visible! * 1. ArcMap: Field Calculator, VB Script: [F__of_Fata]*5 + [F__Serious]*3 + [F__Visible]*1.

        

      

      

        
StatisticsSlide 15

        
Often a first step in data analysis and a chance to think critically about the data. Statistics are returned only for the selected set.

        
ArcGIS Pro: right-click a field header › Statistics, or the Summary Statistics tool.

Data: 480 synthetic crashes made up by a program for teaching, with Collision IDs 1001 to 1480 (Collisions Dataset.csv and Collision.shp are this page's names for them); no row is a real crash record. Every record is dated 04/12/2023 (12 April 2023, one day). The table has the 18 columns listed in step 1, and each road has a single name. Boundaries: U.S. Census Bureau cartographic boundary files (us-atlas, 1:10 million). The map uses Georgia Statewide Lambert (Lambert Conformal Conic, standard parallels 31°25′N and 34°17′N, central meridian 83°30′W) on a sphere; the world view is a plain longitude/latitude grid with only U.S. states drawn. The State Plane landing spot was computed with PROJ for NAD 1983 StatePlane Georgia West (US feet, EPSG:2240). Standard deviation uses n − 1. When a decimal goes into an integer field the lab drops the decimals; ArcGIS may round instead, and either way the decimals are lost. Case sensitivity of = and LIKE depends on the data source, so the lab lets you choose.

# GIS Labs

Interactive labs and narrated animations for learning GIS: coordinate systems and projections, attribute tables and
joins, spatial analysis and linear referencing. Published at https://gis.zhongyuyang.com, in English, 中文, Español,
Français, 한국어 and हिन्दी.

A personal, non-commercial teaching project by Zhongyu Yang. Each page is one self-contained HTML file with its data
embedded; d3, three.js, Turf and the fonts load from public CDNs.

Data: the crashes and horizontal curves are synthetic, generated by a program for teaching; no row is a real crash or
curve record. The base layers (GDOT state-route centerlines, county boundaries) are public data, simplified.
